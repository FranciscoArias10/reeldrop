# Disclaimer

## Purpose of this project

**ReelDrop** is a personal, educational, and experimental project. I built it to learn and to test how a cross-platform desktop app (Python + CustomTkinter + [yt-dlp](https://github.com/yt-dlp/yt-dlp) + FFmpeg) can fetch publicly available media from a pasted link, handle codecs, and present a minimal UI.

It was **not** created with any malicious intent, and it is **not** meant to harm creators, platforms, or anyone else.

## Intended use

- Testing and learning (UI design, media handling, codec compatibility, packaging for Windows and Linux).
- Saving content that **you own**, that you have **explicit permission** to download, or that is released under a license that allows it (e.g. Creative Commons, public domain).
- Personal, offline, non-commercial use where permitted by the law of your country and the platform's terms.
